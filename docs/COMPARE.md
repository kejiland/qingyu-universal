# 与原版 qingyu-blog 功能对照

> 对照基准：原版 [kejiland/qingyu-blog](https://github.com/kejiland/qingyu-blog)
> 上游同步基线 `ad3bfb95`（2026-10-04）+ 之后 3 个提交，原版当前版本 **2.10.63**。
> 本文档每次大版本同步后更新，用来回答一个老问题：**「通用版比之前那版还缺什么？」**

---

## 一、总体结论

| 层次 | 现状 | 说明 |
| --- | --- | --- |
| 前台（访客看到的页面） | ✅ 基本一致 | 前台直接复用原版 `app/public`，只有部署方式不同 |
| 后端 API（数据与业务） | ✅ 全部可用 | 请求原样转发给原版 `worker`，原版有的接口通用版都有 |
| 后台管理界面 | ⚠️ 差距在缩小 | 后台是全新 Vue 重写，原版 18 个入口已覆盖 15 个，**还剩 3 个没搬过来** |
| 云端能力（D1/KV/R2…） | ✅ 有意不同 | 已按设计换成 SQLite/PostgreSQL、本地或 S3 存储、SMTP 等通用方案 |

一句话：**数据和接口不缺，缺的是「后台还有几个页面没搬过来」。**

## 二、已经对齐的部分

### 前台
- 文章列表 / 详情 / 归档 / 标签 / 分类 / 历史 / 系列 / 热门 / 留言板 / 关于 / 友链 / 搜索
- 评论、点赞、订阅、Webmention
- 明暗模式（跟随系统）+ 4 套主题配色 + 五语言（中英日韩印地）
- RSS / sitemap / SEO 服务端渲染 / PWA 与离线缓存
- 音乐播放器、背景动画、图片懒加载

### 后端（原版 51 个 API 文件全部可达）
- 文章、草稿、定时发布、修订历史、相关阅读、文章统计
- 评论（含待审、批量、回复）、留言板、Webmention
- 媒体与音乐上传、备份（列表 / 创建 / 删除 / 读取 / 恢复）
- 订阅者（含群发）、设置、统计趋势与来源
- AI 四个接口（写作助手 / 评论 / 摘要 / Ping），走 OpenAI 兼容接口
- 导入导出（`/api/site-files`）、错误日志、审计日志

> 通用版已把 60 条路径登记进 OpenAPI 文档，与原版接口数量基本一致；
> 个别新接口未登记时也照样能用（走兜底转发），后续随契约持续补登记。
> 只是文档里查不到，后续会逐步补登记。

### 通用版比原版多出来的
- 一键部署脚本（自动装环境、可选端口、可选域名 / IP、体检、升级、备份、恢复、回滚、卸载）
- SQLite 与 PostgreSQL 双数据库、本地磁盘 / S3 兼容存储、SMTP 发信
- Docker Compose 一键部署、`doctor` 体检（含界面配色可读性自检）
- 后台首次上手引导、首页站点概览卡片、界面对比度自检工具

## 四、还缺什么（后台页面）

原版后台侧栏 18 项。**2026-10-07（v0.9-p → v0.9-q）补齐 P0 三项 + P1 两项后**，
新后台已覆盖 15 项（侧栏 14 个入口 + 新建文章按钮），**还剩 3 项**：

> ✅ 已做：标签管理 `/admin/tags`、系列管理 `/admin/series`、待审评论 `/admin/comments/pending`、
> 音乐管理 `/admin/music`、导入导出 `/admin/import-export`
> （侧栏新增这 5 个入口，待审带数量角标），风格与其余页面一致。

| --- | --- | --- | --- | --- |
| P0 ✅ 已做 | 标签管理 | `/admin/tags` | ✅ 就绪 | 批量改名 / 合并 / 删除标签 |
| P0 ✅ 已做 | 系列管理 | `/admin/series` | ✅ 就绪 | 系列排序、封面、简介 |
| P0 ✅ 已做 | 待审评论筛选 | `/admin/comments/pending` | ✅ 就绪 | 评论页「待审」标签页 + 侧栏数量角标 |

### 编辑器里的功能（后端都有，界面没接）

| 功能 | 后端接口 |

| AI 写作助手 | `/api/ai/assist` |

### 其他小差距
- 高级设置里的导航、页脚、友链、广告位目前是 **JSON 文本框**，原版是可视化拖拽编辑器（功能可用，但不够友好）
- 订阅者目前只有列表 / 删除 / 群发，缺**分组与单个编辑**
- 接口文档已登记 60 条路径，与原版接口数量基本一致

## 五、有意做的不一样（不算缺）

| 原版（Cloudflare 深度绑定） | 通用版 |
| --- | --- |
| Workers 运行 | Node.js 容器 |
| D1 数据库 | SQLite（默认）/ PostgreSQL |
| KV 缓存与去重 | 数据库 + 可选 Redis |
| R2 对象存储 | 本地磁盘 / 任意 S3 兼容存储 |
| Resend 发信 | SMTP 默认，Resend 可选 |
| Workers Cron 定时 | 内置调度器 + 系统定时任务 |
| Cloudflare 国家码统计 | 可选 GeoIP，可关闭 |
| Cloudflare 缓存清除 | 应用层缓存 |

## 七、以后怎么防止再落后

每次同步原版后，跑一遍这三步：

1. `git log ad3bfb9..HEAD` 看原版新增了什么
2. 对照本文档第四节，确认没有漏搬的页面
3. 跑 `npm run check:contrast`、`npm --prefix admin run typecheck`、`node scripts/build-frontend.mjs`
